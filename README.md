# University Engineering Projects by Gabriel Cavuquila
This repository contains summaries and supporting materials for six academic projects completed as part of my Bachelor of Engineering Technology in Electrical Engineering at the Cape Peninsula University of Technology.

---

## 📁 Project 1: MATLAB Simulink - Three-Phase Induction Motor Analysis
**Description:**  
Analysis of a 1.1kW, 380V, 50Hz double squirrel cage induction motor using MATLAB Simulink. The project covers parameter extraction from the motor nameplate, theoretical performance calculations, and Simulink model validation.

**Technologies Used:**  
- MATLAB/Simulink  
- Three-Phase Motor Theory  
- Electrical Machines Calculations

**Highlights:**  
- Modeled motor with scopes for real-time measurements  
- Simulated values compared against analytical results  
- Deviations analyzed and interpreted for accuracy improvement

---

## 📁 Project 2: Microgrid Design Using Conventional and Renewable Energy Sources
**Description:**  
A comprehensive study and simulation of a microgrid system combining diesel generation with solar (PV) and battery energy storage (BESS) to support a town’s electrical needs. The goal was to improve power factor, enhance frequency stability, and evaluate renewable penetration.

**Technologies Used:**  
- RSCAD by RTDS  
- Diesel Generator, PV System, BESS  
- Load simulation and frequency measurement

**Highlights:**  
- Simulated grid-connected and islanded modes  
- Power factor tuning and fault recovery tested  
- Addressed real-world implementation constraints and budget

---

## 📁 Project 3: Aircraft Communication System Using AM Modulation
**Description:**  
A proposal for an airport’s voice and text-based communication system using Double Side Band Full Carrier – Amplitude Modulation (DSBFC-AM), optimized for spectral efficiency and operational simplicity.

**Technologies Used:**  
- DSBFC-AM  
- Frequency Division Multiplexing (FDM)  
- Analog components: LM3886, LMX2694-EP, LTC6431-20, 74HC4067

**Highlights:**  
- Calculated bandwidth and channel requirements for airport communication  
- Revenue modeling based on takeoff and landing frequencies  
- Hardware component justification and system scaling recommendations

## 📁 Project 4: Tank Level Control using PLC
**Description:**  
A ladder logic program was developed using PLCnext and simulated with Factory IO to automate the filling and staged discharge of a tank. The system utilizes analog inputs, timers, manual overrides, and visual indicators for efficient process control.

**Technologies Used:**  
- PLCnext Engineering Software  
- Factory IO Simulation  
- Ladder Logic, Analog Sensors

**Highlights:**  
- Accurate analog level conversion and valve control (0–10 scale)  
- LED and lamp-based status feedback  
- Emergency stop and forced discharge functionality

---

## 📁 Project 5: Boxes Counter Automation using PLC
**Description:**  
An automated system to count and group boxes into batches using PLCnext and Factory IO. The system tracks each box and manages conveyor movement to prevent collisions and ensure structured output.

**Technologies Used:**  
- PLCnext Engineering Software  
- Factory IO Simulation  
- Timers, Counters, Latches

**Highlights:**  
- Visual counters for both boxes and batches  
- Interruptible processes with emergency stop and reset  
- Delayed transitions for controlled output

---

## 📁 Project 6: Control Systems Modeling and PI Controller Design
**Description:**  
A control systems project analyzing a second-order RLC system. Simulink was used to simulate both open-loop and closed-loop configurations, with a PI controller designed to meet overshoot, settling time, and error requirements.

**Technologies Used:**  
- MATLAB/Simulink  
- Time-Domain System Modeling  
- PI Controller Design

**Highlights:**  
- Modeled system using differential equations and Laplace transforms  
- PI controller reduced steady-state error to 5% and overshoot to 17.1%  
- Settling time improved from 33s to under 0.1s
